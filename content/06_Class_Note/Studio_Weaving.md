## Colour terms
hue: one color
hue family: variations
value: comparison with gray 
saturation
tint: addition of white=decrease saturation and lightens value
tones: the addition of the same value of gray = decreases saturation
shading: add black=decrease saturation and darkens value
adding complement: create dullness, neutral gray/brown color

## Mixing color with yarn
warp=blue
weft=red
->perceives purple in the fabric

warp=red
weft=green
->perceives muted brown

different weave structure=pattern of a fabric
- plain weave: equally see warp and weft
- twill creates diagonal lines, how many are lifted at one time
	- 1/3 twill, warp is dominant
	- 3/1 twill, weft is more dominant

color and textures can be experimented with twill

## Contrasting colors
cancel each other when mixed
in stripes: based on proportions, different effect can be made
