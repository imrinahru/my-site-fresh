## Explore the act of coding

- コードの身体性, embodiment of code
- Homo sapiens - Homo ladens - homo faber - homo codens
- About rules, algorithms, randomness, and autonomy
- How AI adds up to the course of generative art?
- Work process:
	- Open up a canvas
	- start with 1 stream
	- connect different streams
	- Write live
	- motion is achieved by having variables
		let x =0;
		x ++;
	- random is 隠し味 (secret ingredient)
	- for () for repetition, grids
	- if() {} else {} used in 10 PRINT, changing random changes pattern
	- translate() changing coordinate
		push()... pop() to create a block that can be stopped
