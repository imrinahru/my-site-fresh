# How to Tap


Tapping on a metal/plastic/hard wood surface can make a joint that can be taken apart and re-built easily.


About screw size and tapping size

wood screw (pointy ones) are not for this

For machine screws, 
In 6-32, 32 us the number of threads per inch. So a 32 is a diner screw as compared to a 24, which is a coarse screw for rigorous holding. (NC: National Coarse)

About drill size

Drill size is written on the bid.
It can have a number or a fraction, based on different systems. Look at handout.


---

## Draw Layout

- Using a combination square
- Using a divider to repeat intervals
- Using a scribe to draw on metal/plastic
- Using a center punch to dim the place you want to drill

## Drilling

- Acrylic can be drilled by hand drill
- Use a scrap as back support
- Also use a clamp, cutting lubricant (or water for acrylic) if necessary
- Try to hold the drill and push it into the material, I find it easier to use as much body weight as possible to press down the drill.
- Start with strong pressure and go slowly, then less pressure but drill spin faster

- Using a drill press, change bid 
- Speed is controlled by a 2-belt system, rpm(revolution) input is translated into output
- wood at a faster speed (soft), around 500~675
- aluminum at slower speed 400~

## Tapping

There are through hole tapping tool and blind hole tapping tool.
Start with through hole for centering, then if you want the screw to be part way in, switch to a blind hole tool to make sure the threading is put all the way down. See handouts.
