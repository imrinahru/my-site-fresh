## About Weaving

- It's an interlacing technique
- warp: vertical, need to be strong
- weft: horizontal (right and left), anything, wool, acrylic
- pictorial possibility
	- diagonal shape
	- weft doesn't need to go right to left edge
- selvedge, threads at the edge
- **weft facing**, you can only see the weft, covering up the warp thread, designed by weft
- have a paper design behind
	- tapestry cartoon

## Preparation

- measure arm length
- make a yarn butterfly
- thread the needle

## Tapestry weaving

- weave a little header using warp thread
- Shed: an opening to pass thread in
	- odd shed: 1, 3 warp up
	- even shed: 2, 4 warp up
- Alternate 2 sheds creates plain weave/tabby, which is a fundamental, strongest structure
- Using a table loom, more variation of sheds can be created
- A pick: 1 color of weft
	- pick and pick
- Bubble pattern
	- Color A, Color B
	- AAAB: aligned bubbles
	- AAAAB: misaligned bubbles
- Checkerboard pattern
	- Repeat color until you want the checkerboard to shift
	- ABABAABABAABA..
- Interlocking the weft
- Changing colors in the mid-way
	- slit techniques: great for cartoon
	- dovetail joint: a raised effect
	- weft interlock: tug to create a smooth surface

## Colour terms
hue: one color
hue family: variations
value: comparison with gray 
saturation
tint: addition of white=decrease saturation and lightens value
tones: the addition of the same value of gray = decreases saturation
shading: add black=decrease saturation and darkens value
adding complement: create dullness, neutral gray/brown color
